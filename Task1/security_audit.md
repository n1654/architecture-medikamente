# Аудит мер безопасности и выявление проблемных зон

| Процесс | Текущее состояние | Требования по безопасности | Проблемы |
| --- | --- | --- | --- |
| **Регистрация пациента** | Excel на общем диске | Шифрование PII, доступ по RBAC, аудит, минимальный набор данных | Избыточность, нет контроля доступа, данные в открытом виде, риск утечки.|
| **Запись к специалисту** | Excel и файлы на общем диске | Интеграция с CRM, автоматическая проверка доступности специалистов. | Ручной ввод, ошибки, избыточность данных. |
| **Оплата услуг** | Данные в 1С и Excel, ККМ интегрированы через OLE | PCI DSS, шифрование платежей, RBAC | Дублирование данных, уязвимость OLE, нет MFA. |
| **Закупки оборудования** | Учёт в 1С, заявки по email. | Контроль цепочки поставок, цифровые подписи, RBAC | Нет верификации поставщиков, риск мошенничества. |
| **Зарплата, налоги, кадры** | Учёт в 1С, доступ у трех сотрудников | Защита персданных сотрудников (152-ФЗ), аудит изменений, MFA. | Нет шифрования зарплатных ведомостей, общие логины. |
| **Хранение мед. карт** | Excel, PDF на общем диске | Шифрование, RBAC, аудит доступа | Нет контроля доступа, данные в открытом виде. |
| **Обработка анализов** | Результаты в PDF/JPG, передаются вручную или по email. | Интеграция с API лаборатории, шифрование данных, RBAC | Риск утечки данных, нет автоматизации |
| **Управление доступом** | Только доменная аутентификация (AD) | RBAC/ABAC, MFA | Нет ролевой модели |
